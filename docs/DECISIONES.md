# Decisiones

1. Se reconstruyó primero un producto mínimo usable debido a la pérdida del árbol de trabajo anterior.
2. Sin variables de Supabase, la interfaz usa `localStorage` como modo demostración explícito; no reemplaza la persistencia multi-tenant de producción.
3. Los módulos operativos comparten un tablero reutilizable para mantener consistencia, búsqueda, alta, baja y exportación CSV.
4. Los nombres y contenidos son genéricos; no se incluye información perteneciente a una clínica real.
